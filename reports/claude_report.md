- `SubjectGrid`: Responsive grid for curriculum discovery.
- `TopicList`: Navigational drill-down for subjects.
- `GoalInput`: The primary interface for self-directed missions.
- `RoadmapView`: Day-by-day study task engine.
- `QuizEngine`: Advanced AI-driven knowledge checking with buffer-prefetching.

### **B. AI-Orchestration Layer**
- **Dynamic System Prompts**: Created `services/systemPrompts.ts` which provides the "brain" with localized or Scholarly contexts per request.
- **Zod-Validated JSON API**: Every AI response for roadmaps and quizzes is validated against Zod schemas. If the AI hallucinates, a strict retry-loop is triggered.
- **API Strategy**: Primary (Claude 3.5 Sonnet) and Fast-Fallback (Groq/Llama 3.1) are both supported.

### **C. Database & Security**
- **Supabase Migration**: Implemented a new core schema for `profiles`, `subjects`, and `topics`.
- **Mandatory RLS**: Row Level Security is active on the `profiles` table to ensure data isolation.
- **Extended Seeding**: Seeded 12 KICD High School subjects and 12 broad University Faculty paths with visual iconography.
